AgriSense – Agriculture Management Web Application

About the Project

AgriSense is a web-based agriculture project developed using Python and Django. It provides a structured platform for agriculture-related features through a web interface.

Technologies Used

- Backend: Python, Django
- Frontend: HTML, CSS
- Database: SQLite (if configured in the project)
- Version Control: Git and GitHub

Project Structure

- "AgriSense/" – Main Django project configuration
- "accounts/" – Accounts-related application
- "farm/" – Farm-related application
- "templates/" – HTML templates
- "manage.py" – Django project management utility

Key Learning Outcomes

- Building a web application using Django
- Understanding Django apps, views, URL routing, and templates
- Organizing a Python web project
- Using Git and GitHub for version control

How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/Pranesh307/AgriSense.git

2. Open the project folder:
   
   cd AgriSense

3. Create and activate a virtual environment:
   
   python -m venv venv
   
   Windows:
   
   venv\Scripts\activate

4. Install the required dependencies:
   
   pip install django

5. Run database migrations:
   
   python manage.py migrate

6. Start the development server:
   
   python manage.py runserver

7. Open this URL in your browser:
   "http://127.0.0.1:8000/"
